# Neovim プログラミング逆引き手順書

このドキュメントは、Neovimでプログラミングを行う際に「やりたいこと」から操作方法を探せる逆引き手順書です。

## キー表記について

- **`<CR>`** → Enter キー
- **`<Esc>`** → Escape キー
- **`<Tab>`** → Tab キー
- **`<BS>`** → Backspace キー
- **`<Space>`** → スペースキー
- **`<leader>`** → リーダーキー（この設定では**スペースキー**）
- **`<C-x>`** → Ctrl + x（例: `<C-v>` は Ctrl + v）
- **`<S-x>`** → Shift + x
- **`<A-x>`** → Alt + x（Option キー）

## 📁 ファイル操作

### ファイルを開きたい

#### ファイルエクスプローラーから開く
1. **`<leader>b`**（スペース + b）でファイルツリーを表示
2. カーソルでファイルを選択
3. **`<CR>`** または **`o`** で開く
   - **`<C-v>`**: 縦分割で開く
   - **`<C-x>`**: 横分割で開く
   - **`<C-t>`**: 新しいタブで開く

#### ファイル名で検索して開く
- **`<leader>p`**（スペース + p）: Telescopeでファイル検索
  - 入力するとリアルタイムで絞り込み
  - `<CR>` で選択したファイルを開く

### ファイルを作成したい

1. **`<leader>b`** でファイルツリーを表示
2. 親ディレクトリに移動
3. **`a`** を押す
4. ファイル名を入力（ディレクトリを作る場合は末尾に `/` を付ける）
5. `<CR>` で確定

### ファイルを削除したい

1. **`<leader>b`** でファイルツリーを表示
2. 削除したいファイルにカーソルを移動
3. **`d`** を押す
4. 確認メッセージで **`y`** を押す

### ファイルを移動・コピーしたい

#### 移動
1. **`<leader>b`** でファイルツリーを表示
2. 移動したいファイルにカーソルを移動
3. **`x`** を押してカット
4. 移動先のディレクトリに移動
5. **`p`** を押して貼り付け

#### コピー
1. **`<leader>b`** でファイルツリーを表示
2. コピーしたいファイルにカーソルを移動
3. **`c`** を押してコピー
4. コピー先のディレクトリに移動
5. **`p`** を押して貼り付け

### ファイル名を変更したい

1. **`<leader>b`** でファイルツリーを表示
2. リネームしたいファイルにカーソルを移動
3. **`r`** を押す
4. 新しいファイル名を入力
5. `<CR>` で確定

### ファイルを保存したい

- **`:w`** または **`<leader>w`**: ファイルを保存

### ファイルを保存せずに閉じたい

- **`:q!`** または **`<leader>q`**: 保存せずに終了

## 🔍 コード検索

### ファイル内で文字列を検索したい

- **`/`**: 前方検索（例: `/検索文字列` で Enter）
- **`?`**: 後方検索
- **`n`**: 次の検索結果に移動
- **`N`**: 前の検索結果に移動
- **`*`**: カーソル下の単語を前方検索
- **`#`**: カーソル下の単語を後方検索

### プロジェクト全体で文字列を検索したい

- **`<leader>g`**（スペース + g）: Telescopeでライブgrep
  - 入力するとリアルタイムで絞り込み
  - `<CR>` で選択した結果にジャンプ

## ✏️ コード編集

### テキストを入力したい

- **`i`**: カーソル位置の前に挿入
- **`a`**: カーソル位置の後に挿入
- **`o`**: 現在行の下に新しい行を作成して挿入
- **`O`**: 現在行の上に新しい行を作成して挿入

### テキストを選択したい

- **`v`**: 文字単位で選択（ビジュアルモード）
- **`V`**: 行単位で選択
- **`<C-v>`**: 矩形選択（ブロック選択）

### テキストを削除したい

- **`x`**: カーソル下の文字を削除
- **`dd`**: 現在行を削除（カット）
- **`dw`**: 単語を削除
- ビジュアルモードで選択して **`d`**: 選択範囲を削除

### テキストをコピーしたい

- **`yy`**: 現在行をコピー
- ビジュアルモードで選択して **`y`**: 選択範囲をコピー

### テキストを貼り付けたい

- **`p`**: カーソル位置の後に貼り付け
- **`P`**: カーソル位置の前に貼り付け

### 操作を元に戻したい・やり直したい

- **`u`**: アンドゥ（元に戻す）
- **`<C-r>`**: リドゥ（やり直し）

### コードを補完したい

- 入力中に自動で補完ウィンドウが表示されます
- **`<Tab>`**: 次の候補を選択
- **`<S-Tab>`**: 前の候補を選択
- **`<CR>`**: 選択した候補を確定
- **`<C-Space>`**: 手動で補完ウィンドウを開く
- **`<C-e>`**: 補完を閉じる

### スニペットを使いたい

- 補完候補に `[Snippet]` と表示されるものはスニペットです
- **`<Tab>`**: スニペットを展開、または次のプレースホルダーに移動
- **`<S-Tab>`**: 前のプレースホルダーに移動

### コードをフォーマットしたい

- **`<leader>f`**（スペース + f）: 手動でフォーマット
- **保存時**: 自動でフォーマットされます（conform.nvim）
- **`:ConformInfo`**: 現在のバッファで使用可能なフォーマッターを確認

### コメントを付けたい・外したい

- **`<C-_>`**（Ctrl + /）: 行コメントをトグル
- ビジュアルモードで選択して **`<C-_>`**: 選択範囲をコメント化/解除

## 🚀 LSP機能（コード解析・ナビゲーション）

### 定義にジャンプしたい

- **`gd`**: 定義にジャンプ
- **`<leader>jd`**: 定義にジャンプ（覚えやすいキー）
- **`<C-]>`**: 定義にジャンプ（Vim標準）
- **`<leader>jD`**: Telescopeで定義を選択（複数の定義がある場合）

### 宣言にジャンプしたい

- **`gD`**: 宣言にジャンプ

### 実装にジャンプしたい

- **`gi`**: 実装にジャンプ

### 参照を確認したい

- **`grr`**: 参照一覧を表示（Telescope）

### シンボル名を変更したい（リファクタリング）

- **`grn`**: シンボルをリネーム
  - 入力すると、同じシンボルがすべて変更されます

### 型情報やドキュメントを見たい

- **`K`**: カーソル位置のシンボルのホバー情報を表示
  - 型情報、ドキュメント、パラメータなどが表示されます

### コードアクションを実行したい

- **`gra`**: コードアクションを表示
  - 自動インポート追加、未使用変数の削除など、LSPが提案する修正を実行できます

### ジャンプした場所から戻りたい

- **`<C-t>`** または **`<leader><C-o>`**: ジャンプ履歴を戻る
- **`<leader><C-i>`**: ジャンプ履歴を進む

## ⚠️ エラー・警告の確認

### エラーや警告を確認したい

#### カーソル位置の診断情報を表示
- **`<leader>d`**（スペース + d）: カーソル位置のエラー/警告の詳細を表示

#### 診断情報の一覧を表示
- **`<leader>xx`**: Troubleウィンドウを開く/閉じる（すべての診断情報）
- **`<leader>xd`**: 現在のファイルの診断情報を表示
- **`<leader>xw`**: ワークスペース全体の診断情報を表示
- **`<leader>xq`**: Quickfixリストを表示
- **`<leader>xl`**: Locationリストを表示

#### 診断情報の間を移動
- **`]d`**: 次の診断に移動
- **`[d`**: 前の診断に移動

#### 診断アイコンの意味
- **E**: エラー（Error）- 修正が必要
- **W**: 警告（Warning）- 注意が必要
- **I**: 情報（Information）- 参考情報
- **H**: ヒント（Hint）- 改善のヒント

## 🪟 ウィンドウ操作

### ウィンドウを分割したい

- **`<leader>s`**: 横分割（上下に分割）
- **`<leader>v`**: 縦分割（左右に分割）

### ウィンドウ間を移動したい

- **`<leader>h`**: 左のウィンドウに移動
- **`<leader>j`**: 下のウィンドウに移動
- **`<leader>k`**: 上のウィンドウに移動
- **`<leader>l`**: 右のウィンドウに移動

または標準のキー:
- **`<C-w>h`**: 左のウィンドウに移動
- **`<C-w>j`**: 下のウィンドウに移動
- **`<C-w>k`**: 上のウィンドウに移動
- **`<C-w>l`**: 右のウィンドウに移動

### ウィンドウを閉じたい

- **`<C-w>q`**: 現在のウィンドウを閉じる

## 📝 コードナビゲーション

### ファイル内を移動したい

- **`h`**, **`j`**, **`k`**, **`l`**: 左、下、上、右に移動
- **`w`**: 次の単語の先頭に移動
- **`b`**: 前の単語の先頭に移動
- **`0`**: 行の先頭に移動
- **`$`**: 行の末尾に移動
- **`gg`**: ファイルの先頭に移動
- **`G`**: ファイルの末尾に移動

### 関数やクラス間を移動したい（Treesitter）

- **`]m`**: 次の関数の開始位置へ移動
- **`[m`**: 前の関数の開始位置へ移動

### 関数全体を選択したい（Treesitter）

- **`af`**: 関数全体を選択（around function）
- **`if`**: 関数内部を選択（inner function）
- **`ac`**: クラス全体を選択（around class）
- **`ic`**: クラス内部を選択（inner class）

### インクリメンタル選択したい（Treesitter）

- **`<C-space>`**: インクリメンタル選択を開始
  - 繰り返し押すと、単語 → 行 → 関数 → クラス...と範囲が拡大します

## 🛠️ その他の便利機能

### ターミナルを開きたい

- **`<leader>tt`**: ターミナルを開く
- ターミナルを閉じる: **`<Esc>`** でノーマルモードに戻り、**`:q`** で閉じる

### ファイルツリーを表示/非表示したい

- **`<leader>b`**（スペース + b）: ファイルツリーの表示/非表示をトグル

### ファイルツリー内で操作したい

ファイルツリーがフォーカスされている状態で:

- **`/`**: ファイル名で検索
- **`f`**: ファイル名でフィルタ
- **`F`**: 隠しファイルの表示/非表示を切り替え
- **`?`**: ヘルプを表示（すべてのキーマップを表示）

詳細は「ファイル操作」セクションを参照してください。

## 📚 基本モードについて

Neovimには複数のモードがあります：

| モード名 | 説明 | 用途 |
|---------|------|------|
| **ノーマルモード** | デフォルトのモード | コマンドを実行、移動、編集操作 |
| **インサートモード** | テキスト入力モード | テキストの入力・編集 |
| **ビジュアルモード** | テキスト選択モード | テキストの選択・コピー・削除 |
| **コマンドラインモード** | コマンド入力モード | `:` でコマンドを実行 |

**`<Esc>`** を押すと、どのモードからでもノーマルモードに戻ります。
