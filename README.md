A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## Neovim/Vim 基本操作

### キー表記について

Neovim/Vimのドキュメントでは、特殊キーを以下のように表記します：

- **`<CR>`** → Enter キー（Carriage Return）
- **`<Esc>`** → Escape キー
- **`<Tab>`** → Tab キー
- **`<BS>`** → Backspace キー
- **`<Space>`** → スペースキー
- **`<leader>`** → リーダーキー（この設定ではスペースキー）
- **`<C-x>`** → Ctrl + x（例: `<C-v>` は Ctrl + v）
- **`<S-x>`** → Shift + x
- **`<A-x>`** → Alt + x（Option キー）

### 基本モード

Neovim/Vimには複数のモードがあります：

| モード名 | 説明 | 用途 |
|---------|------|------|
| **ノーマルモード（Normal Mode）** | デフォルトのモード | コマンドを実行、移動、編集操作 |
| **インサートモード（Insert Mode）** | テキスト入力モード | テキストの入力・編集 |
| **ビジュアルモード（Visual Mode）** | テキスト選択モード | テキストの選択・コピー・削除 |
| **コマンドラインモード（Command Mode）** | コマンド入力モード | `:` でコマンドを実行 |

#### モードの切り替え

| キー | モード | 動作 | 説明 |
|------|--------|------|------|
| **`i`** | Normal | インサートモードに入る | カーソル位置の前に挿入 |
| **`a`** | Normal | インサートモードに入る | カーソル位置の後に挿入 |
| **`o`** | Normal | インサートモードに入る | 現在行の下に新しい行を作成して挿入 |
| **`O`** | Normal | インサートモードに入る | 現在行の上に新しい行を作成して挿入 |
| **`v`** | Normal | ビジュアルモードに入る | 文字単位で選択 |
| **`V`** | Normal | ビジュアルモードに入る | 行単位で選択 |
| **`<C-v>`** | Normal | ビジュアルモードに入る | 矩形選択（ブロック選択） |
| **`:`** | Normal | コマンドラインモードに入る | コマンドを入力 |
| **`<Esc>`** | All | ノーマルモードに戻る | どのモードからでもノーマルモードに戻る |

### 基本的な移動

| キー | モード | 動作 | 説明 |
|------|--------|------|------|
| **`h`** | Normal | 左に移動 | 1文字左へ |
| **`j`** | Normal | 下に移動 | 1行下へ |
| **`k`** | Normal | 上に移動 | 1行上へ |
| **`l`** | Normal | 右に移動 | 1文字右へ |
| **`w`** | Normal | 次の単語の先頭に移動 | 単語の先頭へ |
| **`b`** | Normal | 前の単語の先頭に移動 | 前の単語の先頭へ |
| **`0`** | Normal | 行の先頭に移動 | 行の最初の文字へ |
| **`$`** | Normal | 行の末尾に移動 | 行の最後の文字へ |
| **`gg`** | Normal | ファイルの先頭に移動 | ファイルの最初の行へ |
| **`G`** | Normal | ファイルの末尾に移動 | ファイルの最後の行へ |

### 基本的な編集

| キー | モード | 動作 | 説明 |
|------|--------|------|------|
| **`x`** | Normal | 文字を削除 | カーソル下の文字を削除 |
| **`dd`** | Normal | 行を削除（カット） | 現在行を削除（クリップボードに保存） |
| **`yy`** | Normal | 行をコピー | 現在行をコピー |
| **`p`** | Normal | 貼り付け | カーソル位置の後に貼り付け |
| **`P`** | Normal | 貼り付け | カーソル位置の前に貼り付け |
| **`u`** | Normal | アンドゥ | 元に戻す |
| **`<C-r>`** | Normal | リドゥ | やり直し |

### ウィンドウ操作

| キー | モード | 動作 | 説明 |
|------|--------|------|------|
| **`<C-w>h`** | Normal | 左のウィンドウに移動 | 左隣のウィンドウへ |
| **`<C-w>j`** | Normal | 下のウィンドウに移動 | 下のウィンドウへ |
| **`<C-w>k`** | Normal | 上のウィンドウに移動 | 上のウィンドウへ |
| **`<C-w>l`** | Normal | 右のウィンドウに移動 | 右隣のウィンドウへ |
| **`<C-w>s`** | Normal | ウィンドウを横分割 | 現在のウィンドウを上下に分割 |
| **`<C-w>v`** | Normal | ウィンドウを縦分割 | 現在のウィンドウを左右に分割 |
| **`<C-w>q`** | Normal | ウィンドウを閉じる | 現在のウィンドウを閉じる |

### 検索

| キー | モード | 動作 | 説明 |
|------|--------|------|------|
| **`/`** | Normal | 前方検索 | 前方に向かって検索（例: `/検索文字列` で Enter） |
| **`?`** | Normal | 後方検索 | 後方に向かって検索 |
| **`n`** | Normal | 次の検索結果に移動 | 次のマッチに移動 |
| **`N`** | Normal | 前の検索結果に移動 | 前のマッチに移動 |
| **`*`** | Normal | カーソル下の単語を前方検索 | カーソル下の単語を前方検索 |
| **`#`** | Normal | カーソル下の単語を後方検索 | カーソル下の単語を後方検索 |

### 保存と終了

| コマンド | モード | 動作 | 説明 |
|---------|--------|------|------|
| **`:w`** | Command | ファイルを保存 | Write（保存） |
| **`:q`** | Command | 終了 | Quit（変更がない場合のみ終了） |
| **`:wq`** | Command | 保存して終了 | Write and Quit |
| **`:q!`** | Command | 保存せずに終了 | 強制終了（変更を破棄） |

### LSP診断情報（エラー・警告）の表示

コードに「E」（エラー）、「W」（警告）などのアイコンが表示されている場合、以下の方法で詳細を確認できます：

#### カーソル位置の診断情報を表示

| キー | モード | 動作 | 説明 |
|------|--------|------|------|
| **`<leader>d`** | Normal | 診断情報を表示 | カーソル位置のエラー/警告の詳細をフローティングウィンドウで表示 |

#### 診断情報の一覧表示（Trouble.nvim）

| キー | モード | 動作 | 説明 |
|------|--------|------|------|
| **`<leader>xx`** | Normal | Troubleウィンドウを開く/閉じる | すべての診断情報を表示 |
| **`<leader>xd`** | Normal | 現在のファイルの診断情報を表示 | 現在開いているファイルの診断情報 |
| **`<leader>xw`** | Normal | ワークスペース全体の診断情報を表示 | プロジェクト全体の診断情報 |
| **`<leader>xq`** | Normal | Quickfixリストを表示 | Quickfixリストを表示 |
| **`<leader>xl`** | Normal | Locationリストを表示 | Locationリストを表示 |

#### 診断情報のナビゲーション

| キー | モード | 動作 | 説明 |
|------|--------|------|------|
| **`]d`** | Normal | 次の診断に移動 | 次のエラー/警告に移動 |
| **`[d`** | Normal | 前の診断に移動 | 前のエラー/警告に移動 |

#### 診断アイコンの意味

| アイコン | 意味 | 説明 |
|---------|------|------|
| **E** | エラー（Error） | 修正が必要なエラー |
| **W** | 警告（Warning） | 注意が必要な警告 |
| **I** | 情報（Information） | 参考情報 |
| **H** | ヒント（Hint） | 改善のヒント |

## nvim-tree 操作方法ガイド

### 基本操作

#### 表示/非表示の切り替え
- **`<leader>b`** (スペース + b): ツリーの表示/非表示をトグル

### デフォルトのキーマップ（ツリー内で使用）

#### ファイル操作
- **`<CR>`** または **`o`**: ファイルを開く（またはディレクトリを展開/折りたたみ）
- **`<C-v>`**: ファイルを縦分割で開く
- **`<C-x>`**: ファイルを横分割で開く
- **`<C-t>`**: ファイルを新しいタブで開く
- **`<Tab>`**: プレビューを開く（カーソル下のファイルを一時的に表示）

#### ファイル作成・削除
- **`a`**: ファイルまたはディレクトリを追加（新規作成）
- **`d`**: ファイルまたはディレクトリを削除
- **`r`**: ファイルまたはディレクトリの名前を変更（リネーム）
- **`x`**: ファイルをカット（削除準備）
- **`c`**: ファイルをコピー
- **`p`**: カット/コピーしたファイルを貼り付け
- **`y`**: ファイルパスをコピー
- **`Y`**: ファイルの相対パスをコピー

#### ナビゲーション
- **`j`**: 下に移動
- **`k`**: 上に移動
- **`<C-j>`**: 次の兄弟ノードに移動
- **`<C-k>`**: 前の兄弟ノードに移動
- **`<C-r>`**: ルートディレクトリに移動
- **`-`**: 親ディレクトリに移動
- **`~`**: ホームディレクトリに移動

#### ディレクトリ操作
- **`o`**: ディレクトリを展開/折りたたみ
- **`O`**: ディレクトリを再帰的に展開
- **`x`**: 親ディレクトリを折りたたみ
- **`X`**: すべてのディレクトリを折りたたみ
- **`e`**: ディレクトリをエクスプローラーで開く（システム）

#### 検索・フィルタ
- **`/`**: ファイル名で検索（インクリメンタル検索）
- **`f`**: ファイル名でフィルタ（表示/非表示を切り替え）
- **`F`**: 隠しファイルの表示/非表示を切り替え
- **`I`**: Gitの無視ファイルの表示/非表示を切り替え
- **`H`**: ドットファイルの表示/非表示を切り替え

#### Git操作
- **`]c`**: 次のGit変更ファイルに移動
- **`[c`**: 前のGit変更ファイルに移動
- **`u`**: 親ディレクトリに移動してルートを更新

#### その他
- **`<BS>`**: 親ディレクトリに移動
- **`q`**: ツリーを閉じる
- **`<C-]>`**: カーソル下のファイルのディレクトリに移動
- **`<C-e>`**: ツリーを開く/閉じる（トグル）
- **`R`**: ツリーをリフレッシュ
- **`?`**: ヘルプを表示（すべてのキーマップを表示）
- **`g?`**: ヘルプを表示

### 便利な使い方

#### ファイルを開く方法
1. **通常の開き方**: `<CR>` または `o` で現在のウィンドウで開く
2. **分割で開く**: `<C-v>` (縦分割) または `<C-x>` (横分割)
3. **タブで開く**: `<C-t>`

#### ファイルの作成
1. 親ディレクトリに移動
2. `a` を押す
3. ファイル名を入力（ディレクトリを作る場合は末尾に `/` を付ける）

#### ファイルの削除
1. 削除したいファイルにカーソルを移動
2. `d` を押す
3. 確認メッセージで `y` を押す

#### ファイルの移動
1. 移動したいファイルにカーソルを移動
2. `x` を押してカット
3. 移動先のディレクトリに移動
4. `p` を押して貼り付け

#### ファイルのコピー
1. コピーしたいファイルにカーソルを移動
2. `c` を押してコピー
3. コピー先のディレクトリに移動
4. `p` を押して貼り付け

### 現在の設定

- **Git統合**: 有効（変更ファイルが表示されます）
- **トグルキー**: `<leader>b` (スペース + b)

### カスタマイズ

プロジェクト固有の設定は、プロジェクトルートに `.nvim.lua` ファイルを作成して設定できます。
詳細は `.nvim.lua.example` を参照してください。
